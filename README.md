## 🤖 Featured Project: AI Resume Analyzer

> Resume upload karo, ATS score aur AI feedback pao, report download karo.

| | |
|---|---|
| **Problem** | Students ko pata nahi hota ki unka resume ATS pass karega ya nahi |
| **Solution** | Custom scoring logic + Gemini API se personalized feedback |
| **Stack** | Node.js, Express, JavaScript, Gemini API |
| **Deployed on** | Vercel + Railway |

**What it does**
- ATS score calculation
- Skills and missing skills detection
- Resume section analysis
- Action word evaluation
- AI-powered feedback (Gemini)
- Downloadable reports
