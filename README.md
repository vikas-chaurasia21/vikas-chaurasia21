## 🤖 Featured Project: AI Resume Analyzer

> Upload a resume, get an ATS score and AI-powered feedback, and download a detailed report.

| | |
|---|---|
| **Problem** | Students often don't know whether their resume will pass an ATS (Applicant Tracking System) |
| **Solution** | Custom scoring logic combined with personalized feedback from the Gemini API |
| **Stack** | Node.js, Express.js, JavaScript, HTML, CSS, Gemini API |
| **Deployed on** | Vercel (frontend) and Railway (backend) |

**Key Features**
- ATS score calculation
- Skills and missing-skills detection
- Resume section analysis
- Action word evaluation
- AI-powered feedback using the Gemini API
- Downloadable reports
